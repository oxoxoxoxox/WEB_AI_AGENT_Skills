# 기획과 구현 계획

## 아이디어를 실행 가능한 범위로 만들기

1. [프로젝트 브리프](../design/project-brief-template.md)에 사용자, 문제, 핵심 행동, 성공 판단 방법을 적습니다.
2. 사용자 요청과 기존 자료에서 확정한 사실을 먼저 찾습니다. 이미 답이 있는 질문을 반복하지 않습니다.
3. 중요한 미정 사항만 확인하고, 제안과 사용자 결정을 구분합니다.
4. 가능한 접근과 비용·복잡도·제약을 비교해 MVP 범위를 정합니다.
5. 핵심 사용자 흐름과 필요한 화면을 정하고 [디자인 가이드](../design/design-guide.md)를 연결합니다.
6. [구현 계획 양식](implementation-plan-template.md)에 작은 작업 단위와 검증 방법을 적습니다.

계획에는 실제 수정할 파일, 선행 작업, 예상 결과, 확인 방법을 포함합니다. 작은 변경은 짧은 목록으로 충분합니다. 요구사항과 코드가 달라지면 계획을 갱신합니다.

## Superpowers 관련 원문

| 스킬 | 역할 |
|---|---|
| [brainstorming](../references/superpowers/skills/brainstorming/SKILL.md) | 목적과 요구사항을 확인하고 설계 방향 정리 |
| [writing-plans](../references/superpowers/skills/writing-plans/SKILL.md) | 구현 가능한 단위로 계획 구체화 |
| [executing-plans](../references/superpowers/skills/executing-plans/SKILL.md) | 작성한 계획을 순차 실행 |

위 링크는 원문 참조입니다. 전체 Superpowers 절차를 적용하려면 해당 스킬을 읽고 현재 작업에 맞는 범위와 확인 단계를 먼저 정합니다.
