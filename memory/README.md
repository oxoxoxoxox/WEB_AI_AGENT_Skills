# 대화를 이어가기 위한 작업 기록

이 폴더는 여러 프로젝트에서 재사용할 기억 관리 방법을 설명합니다. 실제 개인 기록은 각 프로젝트에 보관합니다. 이 라이브러리에서 임시로 기록하려면 Git에서 제외한 `local/`을 사용합니다.

## 시작할 때

프로젝트의 현재 상태 목차와 관련 인수인계를 읽고, 연결된 코드·문서의 최신 상태를 확인합니다. 이전 노트에 완료라고 적혀 있어도 실제 결과와 어긋나면 현재 상태를 기준으로 갱신합니다.

## 마칠 때

대화 전문 대신 아래 내용을 짧게 남깁니다.

```markdown
# YYYY-MM-DD 작업 주제

## 완료
- 실제 수행한 일과 검증 결과

## 결정
- 확정한 내용, 이유, 근거 파일

## 미해결
- 남은 문제와 필요한 입력

## 다음 행동
- 다음 대화에서 바로 실행할 일
```

비밀키·쿠키·비밀번호는 기록하지 않습니다. 프로필과 설정의 원본을 중복 복사하지 말고 위치를 참조합니다. 저장 후 파일을 다시 읽어 확인합니다.

Basic Memory 같은 도구는 이 기록을 검색·관리하는 선택지입니다. MD 기록만으로도 파일 접근이 가능한 에이전트가 이어갈 수 있지만, 다른 앱·기기·일반 웹 채팅으로 자동 공유되지는 않습니다. 프로그램 설치와 MCP 연결은 별도 설정입니다.
